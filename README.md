# ATMO School — self-study subjects

Landing page with the subject price calculator, application form and confirmation email preview.

Live at https://atmo-school.com (GitHub Pages, custom domain set in `CNAME`).

- `index.html` — the whole site: styles, content and calculator script in one file.
- Prices and bundle discounts are set at the top of the script: `PRICES` and `D2` / `D3`.
- The application form does not send data anywhere yet; connect it to HubSpot before running ads.
